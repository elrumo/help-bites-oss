A pretend host site

This page stands in for webbites or Acme. It loads widget.js and hands it an identity token taken from this page's URL (?pk=…&token=…), which is what a real host would fetch from its own backend.

Mint one with bun scripts/dev-token.mjs <projectId> <userId>.

Add &mode=inline to this page's URL to render the panel below instead of the floating launcher.
